# 闲游 · 浏览器游戏合集

每个游戏放在 `games/<slug>/`，独立维护入口、素材、逻辑和测试；根目录提供合集首页与统一命令。

## 当前游戏

**入画 · 清明上河图**（`games/qingming/`）：用 Canvas 重新绘制的 18000 × 1700 汴京长卷，不使用原画照片作游戏底图。十段风景从街市、虹桥延伸至船坞、水磨、竹林古刹、村社春集与远郊茅舍；300 位街市行人、35 艘舟船、驴车、轿子、水轮、百戏与纸鸢持续活动。虹桥采用高木拱，另两座分别是低石桥和木栈桥；虹桥大船降桅，岸上纤夫拖行。人物有十二类职业形象、衣褶、发髻、帽饰与工具，采用分块缓存渲染长卷。

- **街市跑腿**：向驿使接取三份委托，沿街找到三家店，读掌柜的线索、亲手辨认背篓里的包裹，获得「信」印。任务只标方向，默认不代走、交谈或拾取。
- **汴河拾货**：在码头登舟，90 秒内亲手掌舵打捞五个木箱；箭头与「货箱指引」只提示方向，不会自动驾驶。碰撞漕船扣三秒，登船有保护时间，超时显示得分并可重试。完成获得「舟」印。
- **春日拾趣**：过桥探索两岸，寻找并拾取三件小物，获得「春」印。
- 铜钱散布在整幅长卷，完成活动也可获得；能购买茶、食盒、绣帕，也可在十景舆图雇车远游。首程车票免费，之后每程十二文；旧存档也有首程票。进度保存在当前浏览器。
- **远郊百业**：船坞落锤、水轮磨麦、竹下听钟、三盏藏豆与借风放鸢各有独立操作；初次完成得十五文，重玩得三文。
- **展卷入画**：开场用代码绘制的长卷展开，可跳过并遵循减少动态效果偏好。右上角随时在第一人称与长卷俯瞰间切换，保留位置、任务与铜钱。近处人物用矢量线条绘制，铺面有窗棂、木构、檐瓦、布棚与柜台。

这是依据画作意象创作的可玩场景，并非原画的逐像素、建筑或史学考据复原。

**黄金天台模拟器**（`games/gold-rooftop/`）：像素画风的玩梗小页面。每 10 秒读取一次国际现货金价，按汇率折成元/克；每个买入价对应一栋楼，亏 1% 上 1 层，赚钱的人留在地面。可以添加自己的买入价和昵称，名单保存在当前浏览器。金价来自 gold-api.com，美元兑人民币汇率来自 open.er-api.com（每日参考价），由浏览器直接请求，没有后端；结果只是折算，不含国内溢价与工费，不构成投资建议。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev       # 开发清明上河图，默认端口 5173
npm run dev --workspace=games/gold-rooftop   # 开发黄金天台模拟器，默认端口 5174
npm test          # 游戏与静态服务器测试
npm run build    # 构建合集和每个游戏
npm start        # 生产预览，默认端口 4173，可用 PORT 修改
```

生产入口：`/` 为合集首页，`/games/qingming/` 与 `/games/gold-rooftop/` 为游戏。`dist/` 可部署到普通静态托管服务，包括站点的子目录；资源与合集导航均使用相对路径。

下载的试玩包已经包含 `dist/`。无需 Node 或安装依赖，解压进入合集目录后，一条命令启动：

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
```

在运行此命令的电脑浏览器访问 `http://localhost:4173/games/qingming/`。请不要双击 HTML（模块需要 HTTP）。

### GitHub Pages

仓库管理员在 Settings → Pages 把 Source 设为 **GitHub Actions**。免费账户需使用公开仓库；公开网站不等于私有访问，任何拿到地址的人都能打开。

`.github/workflows/pages.yml` 在合并到 `main` 后自动测试、构建，并把整个 `dist/` 发布到 Pages；也可在 Actions 手动运行。成功后从工作流的 `github-pages` 环境链接打开合集，游戏在其下的 `games/<slug>/`。后续合并到 `main` 会自动更新，无需 Node 常驻服务器。个人进度仍保存在各自浏览器中。

### 操作

| 操作 | 方式 |
| --- | --- |
| 行走 / 划船 | WASD、方向键、手机左下方向盘 |
| 疾行 / 加速 | 按住 Shift、空格或手机「疾行」，消耗脚力 |
| 交谈 / 送货 / 拾取 | 走近后按 E、点身边人物或互动按钮；送货需选择正确包裹 |
| 任务方向 | 点任务或远处人物，只显示方向与距离，不自动行走 |
| 可选辅助寻路 | 点击地面、舆图，或明确点「辅助寻路」；到达后仍需亲手互动 |
| 看风景 | 拖动画面；「归位」回到自己，滚轮、双指或 + / − 缩放 |
| 第一人称 | 右上角切换；W/S 前后、A/D 侧移，左右方向键或拖动画面转头，滚轮 / 双指调整视野 |
| 暂停 | P 或右侧暂停按钮；对话期间也暂停计时 |

声音默认关闭，右上角可开启合成音景：街市拨弦、船坞敲击、古刹疏钟、春集快板与田间鸟鸣，随地区切换变奏，而不是持续单音。暂停与后台静音，对话期间背景音乐静音，但操作钟音和奖励音保留。刷新会保留铜钱、任务、探索、位置、缩放、视角与朝向，以及进行中的拾货挑战（剩余时间和货箱）；声音偏好在下次触摸后恢复，遵守浏览器自动播放限制。手记里的「重新启程」有二次确认。场景不等待字体下载；字体到达后再重绘文字。

合集与游戏复用同一个字体文件；首页在构建时读取 Vite manifest，避免写死旧路径或散列。新增界面汉字时，可用 `fonttools[woff]` 与 Noto Serif SC 源字体运行 `python3 scripts/subset-font.py /path/to/NotoSerifSC.ttf`，重新生成覆盖合集与游戏文字的常规字重子集。完整字体不随项目分发。

## 添加游戏

1. 新建 `games/<slug>/`，包含自己的 `package.json`、入口、素材和测试。
2. 提供 `dev`、`build`、`test` 命令；构建到 `dist/games/<slug>/`，静态资源使用相对路径。
3. 在根目录 `index.html` 添加实际可玩的游戏入口。
4. `npm install` 注册 workspace，运行根目录测试和构建。

## 实现与许可

`game.js` 维护道路图、路径搜索与存档校验；`scene.js` 绘制长卷，`eye.js` 绘制第一人称透视；`activities.js` 提供五种远郊小游戏，`audio.js` 合成音景；`main.js` 连接输入、任务和游戏循环。字体及创作边界见 `games/qingming/CREDITS.md`。

没有账号、服务器端存档、统计跟踪或 service worker；除黄金天台模拟器读取行情的两个公开接口外，没有运行时第三方请求；不承诺首次断网加载。Canvas 场景需要现代浏览器与图形支持。

## Discourse 微应用打包

《入画 · 清明上河图》可以按 [linux-do/mapp-developer-guide](https://github.com/linux-do/mapp-developer-guide) 打包成 Discourse 微应用：

```sh
npm run build:mapp --workspace=games/qingming
```

产物是 `dist/mapp/qingming/package/app.zip`。应用 ID 和版本号取自 `games/qingming/mapp/manifest.json`，也可以用环境变量 `MINI_APP_ID`、`MINI_APP_VERSION` 覆盖；每次上传新包前需要提高版本号。打包脚本首次运行时会用 git 拉取指南仓库里的 SDK 打包器（可用 `MINI_APP_SDK_DIR` 指向本地的 `sdk` 目录）。

## 小红书小工具

黄金天台模拟器可以打包成小红书小工具（离线 H5 zip）：

```bash
npm run build:minitool --workspace=games/gold-rooftop
```

产物是 `dist/minitool/gold-rooftop/gold-rooftop-minitool.zip`，`index.html` 在 zip 根目录。小工具容器不能联网，所以这一版没有实时行情：默认现价取自 `games/gold-rooftop/minitool/snapshot.json`（打包前手动更新），进入后由用户自己修改现价。名单和现价保存在容器 Storage（需要小红书 9.46+），版本过旧或读不到版本时不保存。「AI 锐评」（`window.xhs.AI`）和「天台高度榜」（排行榜，9.51+）是内测能力，需要在创服平台勾选对应高级能力和「用户头像和昵称」权限，未开通时入口自动隐藏。上传前需要在创服平台模拟器、Android 真机和 iOS 真机上各验证一次。
