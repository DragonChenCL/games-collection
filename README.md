# 闲游 · 浏览器游戏合集

每个游戏放在 `games/<slug>/`，独立维护入口、素材、逻辑和测试；根目录提供合集首页与统一命令。

## 当前游戏

**入画 · 清明上河图**（`games/qingming/`）：用 Canvas 重新绘制的 6000 × 1700 汴京小城，不使用原画照片作游戏底图。木构屋顶、城门、虹桥、河道和田野由代码绘制；115 位街市行人、过桥人群、13 艘漕船、柳枝、酒旗、炊烟和飞鸟持续活动。

- **街市跑腿**：向驿使接取三份委托，实际沿街走到三家店交货，获得「信」印。
- **汴河拾货**：在码头登舟，亲自操船，60 秒内打捞五个木箱。碰撞漕船扣时，完成获得「舟」印，可重试。
- **春日拾趣**：过桥探索两岸，寻找并拾取三件小物，获得「春」印。
- 铜钱可沿途拾取、完成活动获得，也可在茶坊消费恢复脚力。进度保存在当前浏览器。

这是依据画作意象创作的可玩场景，并非原画的逐像素、建筑或史学考据复原。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev       # 开发清明上河图，默认端口 5173
npm test          # 游戏与静态服务器测试
npm run build    # 构建合集和每个游戏
npm start        # 生产预览，默认端口 4173，可用 PORT 修改
```

生产入口：`/` 为合集首页，`/games/qingming/` 为游戏。`dist/` 可部署到普通静态托管服务，包括站点的子目录；资源与合集导航均使用相对路径。

下载的试玩包已经包含 `dist/`。无需 Node 或安装依赖，解压进入合集目录后，一条命令启动：

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
```

在运行此命令的电脑浏览器访问 `http://localhost:4173/games/qingming/`。请不要双击 HTML（模块需要 HTTP）。

### 操作

| 操作 | 方式 |
| --- | --- |
| 行走 / 划船 | WASD、方向键、手机左下方向盘 |
| 疾行 / 加速 | 按住 Shift、空格或手机「疾行」，消耗脚力 |
| 交谈 / 送货 / 拾取 | 走近后按 E，或点击底部互动按钮 |
| 自动寻路 | 点击地面、舆图或任务；不会瞬间传送，跨河经过虹桥 |
| 看风景 | 拖动画面；⌖ 按钮回到自己，滚轮或 + / − 缩放 |
| 暂停 | P 或右侧暂停按钮；对话期间也暂停计时 |

声音默认关闭，右上角可开启合成环境音。刷新会保留铜钱、完成状态、探索地点和步行位置；进行中的拾货挑战不保存计时，返回码头重试。手记里的「重新启程」有二次确认。

## 添加游戏

1. 新建 `games/<slug>/`，包含自己的 `package.json`、入口、素材和测试。
2. 提供 `dev`、`build`、`test` 命令；构建到 `dist/games/<slug>/`，静态资源使用相对路径。
3. 在根目录 `index.html` 添加实际可玩的游戏入口。
4. `npm install` 注册 workspace，运行根目录测试和构建。

## 实现与许可

`game.js` 维护道路图、路径搜索与存档校验；`scene.js` 绘制城市场景与动态实体；`main.js` 连接输入、任务和游戏循环。字体及创作边界见 `games/qingming/CREDITS.md`。

没有账号、服务器端存档、统计跟踪、运行时第三方请求或 service worker；不承诺首次断网加载。Canvas 场景需要现代浏览器与图形支持。
