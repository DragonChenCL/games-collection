# 闲游 · 浏览器游戏合集

每个游戏放在 `games/<slug>/`，独立维护入口、素材、逻辑和测试；根目录提供合集首页与统一命令。

## 当前游戏

- **入画 · 清明上河图**：`games/qingming/`，基于张择端公版原画的长卷探索游戏。三个可完成的任务：虹桥行舟时机挑战、茶坊顺序记忆、郊野寻找纸鸢。支持触屏、鼠标与键盘，进度仅保存在本机浏览器。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev       # 开发清明上河图，默认端口 5173
npm test          # 所有游戏的单元测试
npm run build    # 构建合集和每个游戏
npm start        # 生产预览，默认端口 4173，可用 PORT 修改
```

生产入口：`/` 为合集首页，`/games/qingming/` 为清明上河图。构建产物在 `dist/`，可以部署到支持静态目录的普通托管服务。游戏入口及静态资源使用相对路径。

### 操作

- 拖动画卷探索；点击下方地点或缩略图快速移步。
- 点击画面让游人移动；方向键或 WASD 行走。
- 点击红色人物标记交谈，或靠近后按 E。
- 虹桥挑战可点击落篙或按空格。三次成功即可过桥，失误不清空进度。
- 完成茶点记忆和纸鸢任务后，在「汴京手记」查看三个印记。
- 音乐默认关闭，右上角可开启。重置进度需要再次确认。

## 添加游戏

1. 新建 `games/<slug>/`，包含自己的 `package.json`、入口、素材和测试。
2. 提供 `dev`、`build`、`test` 命令；构建到 `dist/games/<slug>/`，静态资源使用相对路径。
3. 在根目录 `index.html` 添加实际可玩的游戏入口。不要添加虚假的可玩占位卡。
4. `npm install` 注册 workspace，运行根目录测试和构建。
