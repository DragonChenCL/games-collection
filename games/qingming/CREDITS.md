# 素材与许可

## 画卷

- 张择端（1085–1145），《清明上河图》，北宋，故宫博物院藏。
- 来源：https://commons.wikimedia.org/wiki/File:Alongtheriver_QingMing.jpg
- 下载镜像：https://free-images.com/display/alongtheriver_qingming.html
- 原始分辨率：38414 × 1800。游戏本地提供缩放的 JPEG 及缩略图。
- Commons 将该作品与忠实二维复制标记为公有领域（PD-old / PD-Art / PD-US）。画家于 1145 年去世；本作并非当代重绘或受版权保护的数字动画。
- 游戏角色、印章、图标、矢量小船、交互效果及对白均为本项目创作。画卷显示时有亮度与饱和度调整。

## 字体

- Noto Serif SC，Google / Adobe，SIL Open Font License 1.1。
- 来源：https://fonts.google.com/noto/specimen/Noto+Serif+SC
- 上游：https://github.com/notofonts/noto-cjk
- 本地 `song.woff2` 是仅包含本游戏与合集首页所需汉字的子集，用以避免运行时外部字体请求。
- 完整字体许可随素材附在 `public/FONT-LICENSE.txt`。

## 声音

环境音乐与奖励音由 Web Audio API 合成，无外部录音。默认关闭。

## 创作边界

本作是艺术启发的轻量浏览器游戏，不隶属于故宫博物院。人物、对话和任务为虚构；茶点玩法不代表对画中茶坊菜单的历史考据。
